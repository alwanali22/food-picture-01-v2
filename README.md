# Nasi Tumpeng

This entry is an illustration of a festive Indonesian nasi tumpeng — a cone of golden turmeric rice on a banana leaf, ringed with fried chicken, egg, sambal, vegetables, omelette, tempeh and cucumber — for the food-picture-01 competition.

## Usage
The `main.ts` program copies `entry.png` to the directory specified by the `MAKEFUN_OUTPUT_DIR` environment variable.
